# Django Todo App

Ek todo app jis mein har user ki apni alag list hoti hai.

## Features
- Signup, login aur logout
- Kaam add, done aur delete karna
- Har user ko sirf apne kaam nazar aate hain
- Bootstrap se design

## Technologies
Python, Django, SQLite, HTML, CSS, Bootstrap

## Chalane ka tareeqa
1. Repository clone karein
2. `pip install -r requirements.txt`
3. `python manage.py migrate`
4. `python manage.py runserver`
5. Browser mein `http://127.0.0.1:8000/` kholein
